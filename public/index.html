把你自己的资料整理成 JSON 数组导进来，字段：title（短标题，最好 4 字以内）、body（正文）、tags（别名，越多越好召回）、image_query（配图关键词，可选）。

关于

zhmem 是一个中文优先的检索库。它有三层：内置知识库（生活 / 旅游 / 健身 84 条）、个人记忆（你自己存的事）、本地文件索引（你指定的文件夹）。本地命中弱的时候才联网，联网结果都带来源。

对话会先检索这三层，再据此回答。配置了模型（ZHMEM_MODEL_URL / ZHMEM_MODEL）就由模型组织语言，没配就把检索结果写成一段话——两种模式在界面上会标出来，不会假装有模型。

这个窗口是独立运行的版本，和 DSH 插件用的是同一份检索代码，区别只在于一个走 HTTP、一个走 MCP。数据存在本机，两边共用同一个文件。

没有 Python 依赖，只要 Node 22 以上。
