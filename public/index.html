个人记忆

我的知识库

把你自己的资料整理成 JSON 数组导进来，字段：title（短标题，最好 4 字以内）、body（正文）、tags（别名，越多越好召回）、image_query（配图关键词，可选）。

关于

zhmem 是一个中文优先的检索库。它有两层：内置知识库（生活 / 旅游 / 健身 84 条）和个人记忆（你自己存的事）。本地命中弱的时候才联网，联网结果都带来源。

这个窗口是独立运行的版本，和 DSH 插件用的是同一份检索代码，区别只在于一个走 HTTP、一个走 MCP。数据存在本机的 ~/.workbuddy/zhmem-memory.db，两边共用同一个文件。

没有 Python 依赖，只要 Node 22 以上。
